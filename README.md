# NL Alert for Homey

Connect NL Alerts for your location to Homey Flows. The app retrieves active alerts and checks their affected areas against your Homey's configured location.

## How it works

A new matching alert starts a Flow with the message, alert ID, start time and end time as tags. A condition checks whether an alert is currently active, and an action retrieves active alerts as a count, first message and JSON list.

Use these cards to turn on lights or send a notification through your existing automations. The app polls once a minute by default. Settings let you change the polling interval, enable timeline notifications and include short-lived test messages.

## Setup

Use a local Homey running version 12.4 or newer, with an internet connection and the correct Homey location configured. Open the app settings to adjust notification and polling preferences.

## Source layout

`src/nlAlertService.ts` retrieves alerts and determines whether they apply to the configured location. `src/preferencesService.ts` manages settings, and `src/flow/` exposes the Flow cards. The Vue settings interface lives in `settings-ui/` and builds into `settings/`.

## Development

Use Bun for dependencies and scripts. Run these commands from the repository root:

```sh
bun install
bun run build
```

The root build also installs and builds the settings interface.

Edit Homey metadata in `.homeycompose/` and driver compose files where present. The root `app.json` is generated by Homey. `README.txt` and its translations contain the Homey App Store description; this Markdown file documents the GitHub project.
